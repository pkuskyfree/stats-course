第五讲　回归分析的现实应用

会跑回归只是第一步，更重要的是知道结果能说明什么、不能说明什么。

回归能回答什么

描述
学历越高的人工资平均越高吗？回归给出一个平均意义上的斜率。
预测
给定 x 预测 y，关注的是预测准不准，不关心为什么。
因果
多读一年书会让工资提高多少？这要求没有遗漏的混杂因素，仅靠一条回归线往往做不到。
遗漏变量偏误
若真实模型含有与 x 相关的变量 a，而回归中漏掉了它，则 b₁ ≈ β₁ + γ · δ。其中 γ 是 a 对 y 的影响，δ 是 a 对 x 的回归系数。

本讲数据全为模拟生成。真实研究需要真实数据，以及随机实验、工具变量、双重差分等更严格的方法。

实验一：教育回报与遗漏变量偏误

模拟 500 人：工资对数 = 1.5 + 0.08 × 受教育年限 + γ × 能力 + 噪声。真实教育回报是 0.08，但能力强的人往往也读书更久。只对教育年限回归（青色线）会高估，把能力也放进回归（橙色线）则接近真值。

实验二：用残差图诊断模型

拟合线看起来都“还行”，但残差图会暴露问题。切换四种数据，观察右图残差是否随机散布在 0 附近。
