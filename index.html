基础概念

四个词贯穿整门课。读完后去下面的实验里找到它们。

总体与样本
总体是我们关心的全部对象，样本是从中抽取的一部分。统计推断就是用样本去认识总体。
随机变量 X
把随机试验的结果变成数字。离散型取有限或可数个值（如抛 10 次硬币的正面数），连续型可取区间内任意值（如身高）。
概率密度函数 f(x)
连续型随机变量的“浓度”曲线。P(a < X ≤ b) 等于曲线在 a 到 b 之间围成的面积，曲线总面积为 1。离散型对应的是概率质量函数 P(X = k)。
分布函数 F(x)
F(x) = P(X ≤ x)，从 0 单调上升到 1。它是密度曲线从左边累积到 x 的面积，所以 P(a < X ≤ b) = F(b) − F(a)。
期望与方差
期望 μ 是分布的“重心”，方差 σ² 衡量数据围绕重心的分散程度。样本均值 x̄ 和样本标准差 s 是它们的估计。
大数定律与中心极限定理
样本越多，样本均值越接近 μ。把许多样本的均值汇总起来，其分布近似正态，中心为 μ，标准差为 σ/√m。

实验一：密度函数与分布函数

选一个分布并调整参数，再拖动 a、b 两个端点。左图阴影面积，就是右图两个端点高度之差。

实验二：随机数生成器

每次点击都会从所选分布中抽出 n 个随机数。n 较小时图形参差不齐，n 增大后直方图逐渐贴近理论密度，经验分布函数贴近理论分布函数。

实验三：中心极限定理

每次从所选分布中抽 m 个数取平均，重复 3000 次，再画出这 3000 个均值的直方图。即使原分布是偏斜的指数分布，m 变大后均值也会呈钟形。

所有图形均在浏览器中实时计算，刷新页面会生成新的随机数。
