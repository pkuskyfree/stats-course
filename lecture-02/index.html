第二讲　数学期望

期望是分布的重心，也是最好的单点预测。

期望是什么

期望 E[X] 是按概率加权后的平均值。

离散型：E[X] = Σ x · P(X = x)　　连续型：E[X] = ∫ x · f(x) dx
线性性
E[aX + b] = aE[X] + b，E[X + Y] = E[X] + E[Y]。后一式不要求 X 与 Y 独立。
方差
Var(X) = E[(X − μ)²] = E[X²] − μ²，衡量偏离期望的平均平方距离。
最优预测
在所有常数 c 中，使均方误差 E[(X − c)²] 最小的是 c = μ。回归分析正是把这个想法推广到“给定 x 时预测 y”。
大数定律
独立同分布样本的均值 x̄ₙ 随 n 增大趋近 μ，这是用样本估计期望的依据。
